# CGSpec contributor entry

This repository develops CGSpec v2. Read [the method specification](docs/METHOD-v2.md), [engine formats](engine/FORMATS.md) and [the short contract](engine/CONTRACT.md) for the task at hand. The old v1 skills and roles still present in this branch are being replaced; do not treat them as v2 behavior.

Keep the v2 implementation isolated from the live `cgspec` and `cortexgate` repositories until the upgrade rehearsal and independent review pass. Record claims with scoped evidence, add regression tests for substantive defects, and preserve other sessions' work. The user leads goals and taste; the agent carries the method.
